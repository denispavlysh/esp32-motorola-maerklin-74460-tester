# Märklin 74460 / k83 ESP32 Turnout Tester

A custom test bench firmware for ESP32 and an L298N motor driver to test vintage Märklin 74460 C-Track digital decoders (and k83/Viessmann 5231 equivalents). 

## 🚂 The Problem It Solves
Early versions of the **Märklin 74460** decoders (PCB `600099 V1.0`) are based on the **MC145027DW** trinary decoder and **HEF4011BT** CMOS logic. They are notorious for being extremely picky when tested with modern DIY command stations (like DCC++ EX) or standard H-bridges like the L298N. 

The two main issues are:
1. **Strict Timing Requirements:** The `MC145027` requires a strict double-word Motorola packet with a very specific inner pause ($t_1$ = 624 µs) and outer pause ($t_2$ = 5000 µs). If the timing is slightly off, the chip discards the packet.
2. **AC-Coupling / Logic Levels:** The `HEF4011BT` logic struggles with the single-polarity square wave generated by DC motor drivers (L298N) without a real central station's zero-crossing point. 

This sketch solves this by:
* Emulating a highly precise Motorola double packet.
* Automatically flipping track polarity in software (`invertTrack`) to guarantee the CMOS logic registers the signal, regardless of how you wired it to the L298N.
* Increasing the coil pulse duration to `400ms` to reliably switch older 74490 turnouts under mechanical load.

## ⚙️ Hardware Setup
*   **Microcontroller:** ESP32 (e.g., ESP32-WROOM)
*   **Driver:** L298N Dual H-Bridge
*   **Power:** 16V DC Power Supply (min 2A recommended)

### Wiring
| ESP32 Pin | L298N Pin | Description |
| :--- | :--- | :--- |
| `GPIO 32` | `ENA` | Enables the output channel |
| `GPIO 33` | `IN1` | Logic for Rail B (Red) |
| `GPIO 25` | `IN2` | Logic for Rail 0 (Brown) |

*Connect the turnout decoder to `OUT1` and `OUT2` of the L298N.*

## 🎛️ DIP Switch Configuration
This batch tester iterates through addresses **1-1 to 1-6** sequentially. 
Unlike newer decoders, the V1.0 74460 boards use **all 10 DIP switches** to set the address. To test your decoders with this code, set their DIP switches exactly as follows (based on the official Märklin manual):

*   **1-1:** `2, 3, 5, 7, 9, 10` = ON
*   **1-2:** `2, 3, 5, 7, 10` = ON
*   **1-3:** `2, 3, 5, 7, 9` = ON
*   **1-4:** `2, 3, 5, 7` = ON
*   **1-5:** `3, 5, 7, 9, 10` = ON
*   **1-6:** `3, 5, 7, 10` = ON

## 🚀 Usage
1. Hook up the decoders to the L298N track outputs.
2. Set the DIP switches on each decoder to a unique address from 1-1 to 1-6.
3. Flash the code to your ESP32.
4. Apply 16V power to the L298N.
5. The ESP32 will automatically sequence through all 6 turnouts, switching them to "Straight", waiting, and then switching them all to "Turnout".
